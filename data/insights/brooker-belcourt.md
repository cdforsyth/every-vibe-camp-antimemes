## Stage 2: Antimemetic Properties Analysis

### 1. The Compute Gap

**INSIGHT:** Web interfaces (ChatGPT, Claude.ai) are stuck at 20-30 minutes of compute. Since early 2025, models can handle hours of processing, but web apps haven't caught up. Claude Code fills this gap - that's why it's exploding. You're barely scratching the surface with browser-based AI.

**CLASSIFICATION:** Diagnostic

- Surprise: 5
- Shareability: 5

**RESISTANCE TYPE:** Cognitive / Technical

**DIAGNOSTIC VALUE:** 9

**Antimemetic Properties:**
- **Cognitive Antimeme:** We assume web interfaces give us full model capability
- **Technical Antimeme:** The compute time limits aren't visible to users

**Why it resists spreading:**
- "I'm already using Claude/ChatGPT" feels like full access
- The 20-minute limit isn't explicitly communicated
- Web UI is the default experience for most users
- CLI/API feels like "developer stuff"
- The capability gap is invisible - you don't see what you're missing

**What's lost by accepting it:**
- The comfort of the familiar web interface
- The assumption that subscription = full access
- The belief that you're getting the model's full capability

**Verification:**
> "The issue is when you use ChatGPT or the web-based interfaces, you're pretty much only getting 20 to 30 minutes of compute... we've expanded to offer LLMs significantly more time to process. But the web apps have kind of stuck at 20 minutes. And so there's this huge gap."

**INSIGHT:** Without explicit investment philosophy, LLMs give consensus analysis. They're trained on average opinions. You have to tell Claude what makes a great investor - trajectory, acceleration, specific metrics you care about - because by default it gives you what everyone else thinks.

### 3. Prompts as Version-Controlled IP

**INSIGHT:** When prompts hit 8,000 characters, you've outgrown chat windows. Store prompts in GitHub and version control them like code. The prompt library becomes IP - valuable, iterable, and yours. Cloud plugins let you call these prompts with slash commands.

### 6. Flex to the Company, Not the Template

**INSIGHT:** Don't create a fixed dashboard template. Each company guides different metrics - Meta guides revenue/expenses/CapEx/tax rate; another might only guide revenue or EPS. The dashboard should flex to the company, not force the company into your template.

- **Implementation Antimeme:** Requires natural language flexibility that most automation lacks

**Why it resists spreading:**
- Templates are valued for consistency
- "One format for all" feels scalable
- The flexibility required is hard to program traditionally
- Different metrics per company creates comparison challenges
- Standardization is professional norm

**What's lost by accepting it:**
- The consistency of standardized templates

- The efficiency of one-size-fits-all

**Verification:**
